# Profiler Dashboard - Shared Code

TypeScript code shared between Rails gem and Chrome extension for profile rendering.

## Description

This folder contains the profiling dashboard rendering logic with a dynamic tab system. The same code is used by:

1. **Profiler web interface** (Rails gem)
2. **DevTools panel** (Chrome extension)

This ensures a consistent user experience across both interfaces.

## Architecture

### Dynamic Tab System

Tabs are now dynamically generated from **Rails-side collectors**. Each collector defines its own tab configuration via the `tab_config` method:

```ruby
# Rails side
class DatabaseCollector < BaseCollector
  def tab_config
    {
      key: "database",
      label: "Database",
      icon: "🗄️",
      priority: 20,
      enabled: true,
      default_active: true
    }
  end
end
```

The profiler then returns this configuration in the API:

```json
{
  "profile": {
    "tabs": [
      {
        "key": "database",
        "label": "Database",
        "icon": "🗄️",
        "priority": 20,
        "enabled": true,
        "default_active": true,
        "render_mode": "auto",
        "has_data": true
      }
    ]
  }
}
```

The frontend dashboard reads this configuration and generates tabs automatically.

## Main Components

### ProfileRenderer

Main class that generates complete dashboard with header, stats and tabs.

```typescript
import { ProfileRenderer } from './dashboard';

const profile: Profile = // ... data from server
const container = document.getElementById('profile-container');

const renderer = new ProfileRenderer(profile, container);
renderer.render();
```

**Methods:**
- `render()`: Generates complete HTML
- `setTab(tabName: string)`: Changes active tab

### TabRegistry

Registry allowing registration of custom renderers for each tab.

```typescript
import { tabRegistry } from './tab-registry';

// Register custom renderer
tabRegistry.register('my_custom', (profile) => {
  return `<div>Custom content for ${profile.token}</div>`;
});
```

**Rendering modes:**
1. **custom**: HTML provided by backend (`tabConfig.html`)
2. **client**: TypeScript renderer registered in registry
3. **auto**: Fallback to generic JSON rendering

### Tab Renderers

Functions that transform collector data into HTML.

```typescript
export function renderDatabaseTab(profile: Profile): string {
  const data = profile.collectors_data?.database;
  if (!data) return '<div class="empty-state">No data</div>';

  return `
    <div class="database-tab">
      <div class="stat">Queries: ${data.total_queries}</div>
      ...
    </div>
  `;
}
```

## TypeScript Types

### Profile

Main structure containing all data:

```typescript
interface Profile {
  token: string;
  method: string;
  path: string;
  status: number;
  duration: number;
  memory?: number;
  started_at: string;
  collectors_data?: {
    database?: DatabaseData;
    cache?: CacheData;
    dump?: DumpData;
    request?: RequestData;
    [key: string]: any;  // Custom collectors
  };
  tabs?: TabConfig[];  // Tab configuration
}
```

### TabConfig

Tab configuration generated by a collector:

```typescript
interface TabConfig {
  key: string;                           // Unique identifier
  label: string;                         // Display name
  icon?: string;                         // Emoji or icon
  priority: number;                      // Order (smaller = first)
  enabled: boolean;                      // Active or not
  default_active?: boolean;              // Selected by default
  render_mode: 'auto' | 'custom' | 'client';
  html?: string;                         // Pre-rendered HTML (custom mode)
  has_data: boolean;                     // Collector has data
}
```

## Adding a New Tab

### 1. Create Rails Collector

```ruby
class MyCollector < Profiler::Collectors::BaseCollector
  def tab_config
    {
      key: "my_tab",
      label: "My Tab",
      icon: "🔧",
      priority: 150,
      enabled: true
    }
  end

  def collect
    store_data({ custom_data: "value" })
  end
end
```

### 2. (Optional) Create Custom Renderer

If you want custom rendering instead of default JSON:

```typescript
// tabs/my-tab.ts
export function renderMyTab(profile: Profile): string {
  const data = profile.collectors_data?.my_tab;
  return `<div>${data.custom_data}</div>`;
}

// index.ts
import { renderMyTab } from './tabs/my-tab';
tabRegistry.register('my_tab', renderMyTab);
```

### 3. That's it!

Tab will automatically appear in:
- Web interface
- Chrome extension

## Utilities

### escapeHtml(str: string): string

Escapes HTML to prevent XSS.

### formatMemoryMB(bytes?: number): string

Formats bytes to MB with 2 decimals.

```typescript
formatMemoryMB(1048576) // "1.00 MB"
formatMemoryMB(undefined) // "0.00 MB"
```

## Maintenance

When adding new features:

1. **Types**: Add interfaces in `types.ts`
2. **Renderer**: Create renderer in `tabs/`
3. **Export**: Export it from `index.ts`
4. **Registry**: Register it in `tabRegistry`
5. **Styles**: Add styles in `_dashboard.scss`

Both interfaces (web and extension) will automatically use the new code.
